인기순을 한국닌텐도 공식 다운로드 순위로 변경했습니다.

- 한국 공식 순위에 올라 있고 현재 할인 중인 상품만 표시
- 정가·할인 종료·순위 미확인 상품 제외
- 실제 집계 기간과 유료 대상 표시, 기종별 순위를 카드에서 확인
- 공식 페이지에서 최신 집계 기간과 순위를 조회하며 연도·순위값을 고정하지 않음
- 기존 미국 순위 캐시 제거, 출처와 기간이 확인된 한국 순위 캐시 유지

현재 공개 자료는 2026년 상반기 Switch / Switch 2 각각 1~30위입니다. 두 기종의 순위는 따로 집계되며, 전체 기종 보기에서는 Switch 1 다음 Switch 2로 표시합니다. 한국 상품 ID와 기종이 정확히 일치하는 상품만 연결합니다. 인기순에서는 할인 중인 1,000~4,999원 상품도 포함합니다.

본체 e숍의 최근 3일 순위는 외부 조회 경로가 확인되지 않아 사용하지 않습니다. 가격과 할인 정보는 기존처럼 한국 e숍 가격 API를 사용합니다.

Android 7.0 이상 ARM64용입니다. 이전 버전과 같은 서명 키 및 증가한 버전 코드로 찜·캐시를 유지한 업데이트 설치를 지원합니다. 정적 분석, 테스트 56개, 실제 한국 순위 60개 조회, GitHub CI 및 APK 서명·ABI를 검증했습니다.
