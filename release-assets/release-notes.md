새 게임 목록이 일부 누락되더라도 확인된 신규 게임과 변경 정보를 반영하도록 목록 갱신 방식을 수정했습니다.

- 상품 ID별 신규 게임 추가 및 기존 메타데이터 갱신
- 이번 응답에 없는 기존 게임도 보존
- 가격 조회 전에 확인된 게임 목록을 저장하여 가격 조회 실패 시에도 신규 정보 유지
- 일부 미확인 상태와 목록 확인 시도·전체 확인·전체 가격 조회 시각 구분
- 개수 일치를 위한 반복 전체 스캔 제거

실제 닌텐도 API와 기기 저장소 검증에서 기존 4,535개 게임을 유지하면서 신규 82개가 추가된 4,617개 목록이 저장됐고, 가격 조회도 정상 완료됐습니다. 이 개수는 검증 당시 결과이며 앱의 조회 상한이나 고정된 게임 목록이 아닙니다.

정적 분석·테스트 68개와 실제 API 점검을 통과했습니다. Android 7.0 이상 ARM64 기기용이며 이전 버전과 동일한 서명 키 및 증가한 설치 버전 코드를 사용합니다. 기존 앱 위에 업데이트 설치할 수 있습니다.
