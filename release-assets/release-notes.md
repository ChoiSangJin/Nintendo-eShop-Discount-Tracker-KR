전체 게임 목록의 일부 항목을 확보하지 못했을 때 가격 조회까지 중단되던 문제를 수정했습니다.

- 새 목록 수집이 실패해도 검증된 기존 전체 목록으로 가격 갱신 진행
- 기존 목록 사용 안내와 원래 목록 갱신 시각 보존
- 앱 재실행 후에도 안내 유지, 재시도로 새 전체 목록 조회
- 가격 조회까지 실패하면 이전 게임·가격·조회 시각 보존
- 가격 새로고침은 오래된 검증 목록으로도 가격만 갱신

새 게임 정보는 전체 목록 조회가 성공하면 반영됩니다. 목록 갱신을 실패한 상태를 최신 전체 목록으로 표시하지 않습니다.

Android 7.0 이상 ARM64용 APK입니다. v1.4.1과 동일한 서명 키와 증가한 버전 코드로 업데이트 설치를 지원하므로 기존 앱 위에 설치할 수 있습니다.

정적 분석과 테스트 65개, GitHub CI, APK 서명·ARM64 ABI·설치 버전 및 배포 파일 체크섬을 검증했습니다.
